# 织间 · 视觉与交互原型（v1）

这是「织间」的视觉与交互原型，独立于功能版本，用来先把视觉方向定下来，再与功能版本整合。

- 打开 `index.html` 就能运行，不需要构建。字体从 Google Fonts 加载，其余内容都写在这个文件里。
- 原型里的织面数据、穿梭规则、图片取色和尺寸缩放都是**演示用的简化实现**，只用来展示视觉和动效。整合时一律以功能版本的逻辑为准，不要把原型里的这些算法合并进去。
- v1 根据三类插画参考和用户的实物杯垫调整了视觉方向；参考图本身不放进仓库。

## 1. 空间结构

打开网页，整个画面就是一张桦木多层板桌的桌面，照着用户实物照片里的那张桌子画。画面里没有墙，也没有桌子的边缘，所以不会出现像图片边框一样的直线。桌上的每个物件都是入口：

| 物件 | 进入后 | 承载的功能 |
|---|---|---|
| ① 织布机 | 织布机场景 | 穿梭（长按 0.35 秒后拖动）、画笔、填色、拆线、单点微调、撤销与重做；穿梭规则（压几挑几、起始步骤、方向、延续路径、反向回织、交换上下）；按经线范围织入；逐行图解与浮线提醒；纹理和编号显示；缩放与平移 |
| 尺子（压在织布机下方） | 织布机场景，并直接打开「调整织面」 | 宽高 2–200 cm、经线 4–240 根、纬线 4–600 行；按每厘米密度换算；保留原格子，或按比例缩放（缩放后交织关系重设为平纹） |
| ② 毛线篮 | 毛线场景 | 最多 24 色；选当前纬线、设经线颜色、添加线色 |
| ③ 草稿纸和贴在上面的照片 | 草稿场景 | 图片转换（织物照片 / 平面图案、主色数量、纹理简化、忽略浅色细线、完整保留 / 居中裁切、按原图比例），先预览再应用；保存、打开 JSON；导出 PNG / SVG |
| ④ 台灯 | 不进入场景 | 切换白天和夜间。夜里台灯亮起，桌面上有一圈暖光 |
| 两块旧杯垫 | 不能点 | 只是装饰，照着用户织过的杯垫画 |

物件之间的关联：

- 有一根线从篮子里的线团牵到织布机的梭子上。线团和线的颜色都是当前纬线色，换线时一起变。当前纬线团总是放在篮子里离织布机最近的位置。
- 织布机上织着的布、草稿纸上的格子图和织布机场景里的画布，用的是同一份草稿数据。
- 织布机的木框之间是透明的，能透过经线看到桌面，和实物一样。
- 草稿纸上贴的照片就是图片转换的原图，换图后桌上这张也跟着换。
- 场景之间的跳转（比如从织布机点「换线」）会让镜头沿着桌面平移过去，不会先退回全景。

## 2. 视觉方向

**参考了三类插画：** 室内静物画提供空间和平涂色块，nana 的「23:」系列提供物件画法和标注方式，nana 的 SPRING 卡片只借大号数字和那一点玫粉。

**颜色的分工：界面保持中性，颜色留给用户的线和草稿。**

| 角色 | 浅色（白天） | 深色（夜里开灯） | 用途 |
|---|---|---|---|
| 桌面 | 桦木 `#E6D3AE` | `#5A4632` | 整个画面的底色，也是每个场景的底色 |
| 纸 | `#FBF8F0` | `#2D2A26` | 面板、草稿纸 |
| 炭黑 | `#2B2A27` | `#F2EADA` | 文字、选中状态、主按钮 |
| 山毛榉 | `#EBCB97` | `#C9A773` | 织布机、尺子 |
| 玫粉 | `#F0468C` | `#FF6FA8` | **只标「当前」**：当前行的大号数字、锁定的行、长按进度环、浮线提醒、未保存的小点 |
| 台灯橙 | `#F0532E` | `#F0603A` | 台灯、标注上的小圆点 |

示例线色取自用户的实物杯垫：本白、森林绿、薄荷绿、黄绿、信号橙、天蓝、梅子紫、暖灰、淡紫。这些颜色只出现在线团、草稿和装饰杯垫上，按钮和选中框都不用它们。用户画什么颜色都不会和界面的高亮撞色。玫粉之所以能用来标「当前」，正是因为用户的线里没有这个颜色。

**质感：** 工作台上的物件都用 SVG 滤镜 `#crayon` 画成蜡笔的样子：轮廓带一点低频的抖动，不是笔直的线；边缘毛茸茸的；色块里有露出底色的颗粒。线团上画了手绘的线股，篮子用手绘的波浪线表示编织纹。物件不加投影。

**织面画布和所有操作控件保持清楚，不加蜡笔质感**，方便对照着一根一根地织。织布机场景里的织面用平涂色块；开着「经纬纹理」时，纬线在下方的格子里只露出一道细细的经线，不画凸起。

**不用边框和卡片：** 各个场景直接铺在桌面上，没有卡片、阴影或描边框。内容分组只靠留白和少量虚线（像缝线）。织布机场景里只在织面上下各画一根木梁，代替原来围成一圈的木框。弹出层「调整织面」是一张纸，因为它需要和桌面区分开。

**字体：**
- 场景标题和物件名：站酷快乐体
- 正文：思源黑体
- 标注、根数、行数、色号：Courier Prime（打字机字体）
- 当前行的大号数字：Fredoka

**标注：** 用带圈编号、打字机小字和虚线引线来写说明，例如 `① 织布机 loom.`、`( 工作台 · 织布机 )`。逐行图解里的色段也用带圈编号标出。

## 3. 动效规范

| 动作 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 推近 / 拉远镜头 | 760ms | `cubic-bezier(.65,0,.25,1)` | 整张桌子一起缩放平移；推近时其余物件变淡 |
| 场景操作层出现 | 推近开始约 430ms 后，持续 360–500ms | 淡入加回弹 `cubic-bezier(.3,1.4,.5,1)` | 在镜头还没停稳时就开始出现，两段动作接起来 |
| 场景操作层退出 | 320ms | ease | 和拉远同时开始 |
| 物件悬停 | 350ms | 回弹 | 上浮 6px；线团滚动，梭子往里探，照片翘起，灯罩歪一下，标注轻轻摆动 |
| 台灯开关 | 600–800ms | ease | 墙、桌面、纸的颜色一起渐变，暖光慢慢亮起 |
| 长按穿梭 | 0.35 秒玫粉进度环，然后环弹一下，锁行带和梭子开始跟手 | — | 按住时移动超过 8px 就取消长按 |
| 逐行推进 | 250ms | 回弹 | 当前行的圆点放大并变成玫粉 |

打开系统的「减少动态效果」时，镜头直接切换，操作层只做淡入淡出。

## 4. 能力边界在界面上的表达

- 图片转换的结果始终叫「配色草稿」，不用「还原」「识别织法」这类说法。
- 转换设置下方有一块固定的说明，不能折叠，共三条：只记录颜色，应用后交织关系是默认平纹；经纬密度和细线条宽度目前无法可靠识别，细线条可能变窄；花色毛线、阴影和后缝线会干扰取色。
- 示例照片里故意放了一条浅蓝色的细线和一条白色后缝线。预览时能看到蓝线变窄、断开，白线被滤掉，正好用来展示上面这些限制。
- 应用之后会提示「交织关系为默认平纹」，并给出「去织布机调整」的入口。
- 顶栏的保存状态只有「示例草稿」和「有改动 · 未保存」两种，并标明「需手动保存」，不暗示有自动保存。

## 5. 布局适配

- 宽屏是横向构图：织布机在左，毛线篮、草稿和台灯在右。竖屏改成纵向构图：台灯和织布机在上，毛线篮和草稿在下。
- 织布机场景在宽屏上分三栏：工具栏、织面、设置抽屉。中等宽度时抽屉移到下方；手机上工具栏横着排。
- 手机上第一次进入织布机时，织面会自动缩放到适合屏幕的大小。
