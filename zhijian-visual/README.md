# 织间 · 视觉与交互原型（v0）

这是「织间」的视觉与交互原型，独立于功能版本，用来先确定方向，之后再与功能版本整合。

- 打开 `index.html` 即可运行，不需要构建。原型只用 Google Fonts，其余全部内联。
- 原型里的织面数据、穿梭规则、图片取色和尺寸缩放都是**演示用的简化实现**，只用来展示视觉和动效。整合时一律以功能版本的逻辑为准，不要把原型里的算法合并进去。
- 当前版本还没有吸收参考图。收到参考后会更新本文档里的「视觉方向」和「动效规范」，空间结构和功能分布尽量保持不变。

## 1. 空间结构

打开网页看到的是一张俯视的工作台。工作台上的每个物件都是入口：

| 物件 | 进入后 | 承载的功能 |
|---|---|---|
| 织布机 | 织布机场景 | 穿梭（长按 0.35 秒拖动）、画笔、填色、拆线、单点微调、撤销与重做；穿梭规则（压几挑几、起始步骤、方向、延续路径、反向回织、交换上下）；按经线范围织入；逐行图解与浮线提醒；纹理和编号显示；缩放与平移 |
| 尺子（压在织布机下方） | 织布机场景，并直接打开「调整织面」 | 宽高 cm（2–200）、经线 4–240、纬线 4–600；按每厘米密度换算；保留原格子 / 按比例缩放（缩放后交织重设为平纹） |
| 毛线篮 | 毛线场景 | 最多 24 色；选当前纬线、设经线颜色、添加线色 |
| 草稿纸 + 贴着的照片 | 草稿场景 | 图片转换（织物照片 / 平面图案、主色数量、纹理简化、忽略浅色细线、完整保留 / 居中裁切、按原图比例），先预览再应用；保存、打开 JSON；导出 PNG / SVG |

物件之间的关联（让它们看起来是同一个空间，而不是三个按钮）：

- **一根线**从篮子里的线团牵到织布机的梭子上。线团和线的颜色就是当前纬线色，换线时一起变。
- **当前纬线团**永远放在篮子里离织布机最近的位置。
- 织布机上织着的布、草稿纸上的格子图、织布机场景的画布，**都来自同一份草稿数据**，改一处三处一起变，对应「配色与穿线共用同一张草稿」。
- 草稿纸上贴着一张**照片**，表示图片转换的入口；照片换成用户上传的图片后，桌面上的那张也会换。
- 尺子上的标签显示当前**织面尺寸**。

场景之间的跳转（例如从织布机点「换线」到毛线）会让镜头直接沿桌面平移过去，不会先退回全景。

## 2. 视觉方向（v0，待参考调整）

**实物质感 + 扁平描边 + 一点可爱。** 物件用平涂色块和统一的靛青描边，像贴纸；材质靠少量纹理表现（木纹、毛线股纹、亚麻桌面的细格），不用写实的渲染。

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 桌面 | 亚麻灰绿 `#DCE1D2` | 夜间靛灰 `#1E2332` | 工作台底色 |
| 纸 | `#FBFAF4` | `#2A3042` | 面板、标签、草稿纸 |
| 描边 | 靛青 `#26304A` | `#0C101C` | 所有物件和控件的统一描边、硬阴影 |
| 木 | `#E6B676` / `#C68A4A` | `#C99A5E` / `#8F653A` | 织布机、尺子、篮子、梭子 |
| 强调 | 钴蓝 `#2F5BD3` | `#84A2FF` | 选中、主按钮、进度环；与试织的蓝色线条同源 |
| 点缀 | 樱粉 `#F2A0B0` | `#E58C9E` | 胶带、便签，少量使用 |
| 提醒 | 琥珀 `#B8651A` | `#F2AE5A` | 浮线提醒、未保存、能力边界说明 |

- 字体：标题和物件标签用站酷快乐体（ZCOOL KuaiLe），只用在少数地方；正文用思源黑体（Noto Sans SC）；数字、根数、色号用 JetBrains Mono，等宽对齐。
- 控件：胶囊形按钮，2px 描边加 3px 硬阴影，按下时下沉。分隔线用虚线，像缝线。
- 可爱的部分来自物件的动作，不靠表情或贴图：线团悬停时会滚动一下，梭子会往里探，照片的一角会翘起来，标签会轻轻摆动。

## 3. 动效规范（v0）

| 动作 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 推近 / 拉远镜头 | 760ms | `cubic-bezier(.65,0,.25,1)` | 整张桌面一起缩放平移；推近时其余物件变淡并轻微虚化 |
| 场景操作层出现 | 推近开始后约 430ms，持续 360–500ms | 淡入 + 回弹 `cubic-bezier(.3,1.4,.5,1)` | 镜头还在收尾时操作层就开始出现，两段动作衔接 |
| 场景操作层退出 | 320ms | ease | 与拉远同时开始 |
| 物件悬停 | 300ms | 回弹 | 上浮 6px，标签反向摆动 |
| 长按穿梭 | 0.35s 进度环 → 环弹一下 → 锁行带 + 梭子跟手 | — | 进度环跟着按住的位置；按住期间移动超过 8px 就取消长按 |
| 弹层 / 提示 | 250–400ms | 回弹 | 从下方带一点倾斜进入 |

打开「减少动态效果」时，镜头直接切换，操作层只做淡入淡出。

## 4. 能力边界在界面上的表达

- 图片转换的结果始终叫「配色草稿」，不用「还原」「识别织法」这类说法。
- 转换设置下方有一块固定的琥珀色说明，不能折叠：只记录颜色、应用后交织关系是默认平纹；经纬密度和细线条的宽度目前无法可靠识别，细线条可能变窄；花色毛线、阴影和后缝线会干扰取色。
- 应用之后出现提示「交织关系为默认平纹」，并给出「去织布机调整」的入口。
- 顶栏的保存状态在「示例草稿 / 有改动 · 未保存」之间切换，并标注「需手动保存」，不暗示有自动保存。
- 示例照片里故意带了阴影和一条白色的后缝线，预览中能看到它们对取色的干扰。

## 5. 布局适配

- 宽屏时工作台横向构图：织布机在左，毛线篮和草稿在右。竖屏时改为纵向构图：织布机在上，毛线篮和草稿在下。
- 织布机场景：宽屏是「工具栏 | 织布框 | 设置抽屉」三栏，中等宽度时抽屉移到下方，手机上工具栏横排。
- 手机上第一次进入织布机时，织面会自动缩放到适合屏幕。
